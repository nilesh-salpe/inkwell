    What the buttons do

    RaggedRows with more or fewer fields than the header are listed by row number — the usual cause of a broken import
    TidyTrims every cell and pads short rows so the table is rectangular
    → JSONEach row becomes an object keyed by the header; numbers and booleans are converted
    QuotingRFC 4180 — fields containing the delimiter, a quote or a line break are quoted, and "" is an escaped quote

    The delimiter is detected from the first few lines; override it above the table if the guess is wrong. Filtering only affects the view — exports always use the full document.

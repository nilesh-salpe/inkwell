Small tools that get out of your way

No account, no sign-up, no trial. Open a tool, do the work, take the result with you — Markdown to PDF, JSON, YAML and XML to a readable tree, CSV to a real table.

M↓

Markdown editor

Write with a live split preview and export a real PDF — selectable text, proper page breaks, no screenshots.

  • Live preview, syntax highlighting, LaTeX math, Mermaid diagrams
  • PDF, HTML and .md export
  • Tables, task lists, footnotes, GitHub callouts
  • Outline, find & replace, multiple documents
Open the editor → { }

JSON formatter

Validate, format and query JSON. When it breaks you get the exact line and column, not a shrug.

  • Validate with the exact line and column of the fault
  • JSONPath queries — $..author, filters, slices
  • Collapsible tree view — click a key to copy its path
  • Format, minify, sort keys, strip comments and trailing commas
Open the formatter → Y

YAML formatter

Validate, tidy and explore YAML — config files, CI pipelines, Kubernetes manifests.

  • Validate with the exact line and column of the fault
  • YAML ↔ JSON conversion, both directions
  • Multi-document files (---) parsed separately
  • Same tree view and JSONPath queries as the JSON tool
Open the formatter → JWT

JWT decoder

Decode a token, read its claims and find out whether it has actually expired — with the signature checked.

  • Header and payload as a readable tree
  • exp, nbf, iat shown as real dates, with expiry status
  • Signature verification — HS, RS, PS and ES
  • Tokens are never written to storage
Open the decoder → <>

XML formatter

Check that a document is well-formed, re-indent it, and read it as a tree instead of a wall of tags.

  • Exact line and column when it is not well-formed
  • Format at 2 or 4 spaces, or minify
  • XML → JSON, with attributes as @name
  • JSONPath queries over the converted shape
Open the formatter → CSV

CSV viewer

See a delimited file as a real table, and find the row that breaks your import before it breaks it.

  • Ragged rows and unterminated quotes reported by row number
  • Delimiter detected automatically — comma, semicolon, tab, pipe
  • CSV ↔ JSON in both directions
  • Filter rows, and print the table straight to PDF
Open the viewer → ID

ID generator

Generate UUIDs and other identifiers in bulk — and identify any ID you already have.

  • UUID v1, v3, v4, v5, v6 and v7 (RFC 9562)
  • ULID, ObjectId, NanoID and random tokens at any length
  • v7 and ULID stay sorted even generated in one batch
  • Paste an ID to get its format and creation time
Open the generator → \

Escape & unescape

Every representation of a string at once — and, going the other way, whichever decoders actually apply.

  • JSON, HTML, URL, Base64, hex, Unicode, backslash, regex, SQL
  • Unescape tries every decoder and reports what fits
  • Chain decodings — Base64 then JSON, say
  • Copy one result, or push it back into the input
Open the tool → #

Hash & HMAC

Checksum text or a file, generate HMACs with a key, and check a digest against a published checksum.

  • MD5, SHA-1, SHA-256, SHA-384, SHA-512 and CRC32 at once
  • Drop a file to verify a download's checksum
  • HMAC — what webhook signatures are built on
  • Paste an expected digest and the matching algorithm is named
Open the tool → ±

Diff viewer

Compare two texts line by line, with the exact words that changed highlighted inside each edited line.

  • Side-by-side or unified
  • Word-level detail within changed lines
  • Ignore whitespace or case
  • Drop a file onto either side
Open the viewer → .*

Regex tester

Build a pattern against real text, with matches highlighted as you type and every capture group listed.

  • Live highlighting, numbered and named groups
  • Replacement preview with $1 and $<name>
  • All six flags
  • Runaway patterns are stopped, not left to freeze the page
Open the tester → T

Text utilities

Case conversion, line operations and a proper read on how long a piece of writing actually is.

  • camelCase, snake_case, kebab-case, slugify and more
  • Sort naturally, deduplicate, trim, renumber
  • Words, sentences, paragraphs, reading time
  • Most-used words, filler excluded
Open the tools → 01

Number bases

Binary, octal, decimal and hex at once, with bitwise operations and two's complement.

  • 0x, 0b and 0o understood automatically
  • AND, OR, XOR, NOT, shifts and arithmetic
  • 8, 16, 32 or 64-bit widths
  • BigInt throughout — no silent precision loss
Open the converter → ◐

Colour converter

Convert between hex, RGB, HSL and OKLCH, and check contrast before it fails an audit.

  • Every format for each colour, with one-click copy
  • WCAG AA and AAA against any background
  • OKLCH, so lightness changes keep the hue
  • Paste a whole palette at once
Open the converter → 🔒

AES encrypt

Encrypt a message with a passphrase, and decrypt one you have been sent.

  • AES-256-GCM, so tampering is detected
  • PBKDF2-SHA256 key derivation
  • Fresh salt and IV, carried in the message
  • Nothing typed is written to storage
